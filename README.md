# AgroVida Zootecnia
En el año 2032, después de graduarme como Bachiller Técnico en Sistemas del Colegio San José de Guanentá y prepararme profesionalmente en Zootecnia, decido crear mi propia empresa llamada AgroVida Zootecnia.

La empresa ofrece asesorías para ganaderos y productores del campo, además de vender productos para el cuidado y alimentación de animales como bovinos, porcinos, ovinos, aves y mascotas. Para facilitar la comunicación con los clientes, se desarrolla un sitio web donde las personas pueden conocer los servicios, comprar productos, agendar asesorías y contactar directamente con la empresa.

# Planteamiento del problema

# Causas

Muchos productores del campo tienen dificultades para encontrar asesoría profesional en zootecnia de forma rápida y confiable. Además, en algunas zonas rurales el acceso a productos especializados para la alimentación y el cuidado de los animales es limitado.

# Consecuencias

Esto provoca una baja productividad en las fincas, enfermedades en los animales, mayores gastos para los productores y pérdidas económicas por falta de una buena orientación técnica.

# Problema

Actualmente no existe una plataforma digital que reúna en un solo lugar los servicios de asesoría zootécnica, la venta de productos para animales y un sistema sencillo para que los clientes puedan solicitar atención profesional.

# Aporte

El sitio web AgroVida Zootecnia permitirá que los productores encuentren asesoría fácilmente, compren productos desde cualquier lugar y agenden citas sin necesidad de desplazarse, mejorando el bienestar animal y la productividad de las fincas.
