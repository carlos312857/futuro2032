# Stevan Dance Studio

Sitio web de una academia de baile desarrollado como proyecto del Colegio San José de Guanentá.

## Planteamiento del problema

### Contexto

En el año 2032, después de graduarme como Bachiller Técnico en Sistemas del Colegio San José de Guanentá y prepararme profesionalmente en el mundo del baile, decido crear mi propia academia llamada Stevan Dance Studio. Mi objetivo es enseñar diferentes estilos de baile, tanto de manera presencial como virtual, utilizando una página web donde las personas puedan conocer los cursos, reservar clases y comunicarse conmigo fácilmente.

### Causas

Actualmente muchas personas desean aprender a bailar, pero encuentran dificultades para acceder a información clara sobre horarios, precios o disponibilidad de los cursos. Además, muchos profesores independientes aún manejan sus clases únicamente por WhatsApp o redes sociales, lo que hace más difícil organizar reservas y pagos.

### Consecuencias

Esta falta de organización puede provocar pérdida de clientes, confusión con los horarios, dificultad para administrar las inscripciones y una experiencia poco profesional para quienes desean tomar clases.

### Problema

No existe una plataforma propia que permita administrar de forma organizada una academia de baile independiente, donde los estudiantes puedan registrarse, conocer los cursos disponibles, reservar clases y mantenerse informados sobre eventos y promociones esto es muy nuevo, mas que todo por que aplicaciones de estas para tener un registro y actualizaciones de esta manera no se an visto para nada.

### Aporte

Con el desarrollo de este sitio web se busca ofrecer una solución moderna y organizada para administrar la academia Stevan Dance Studio. La plataforma permitira que los clientes consulten la información de los cursos, se registren como estudiantes, reserven clases, conozcan eventos especiales y establezcan una comunicación mas facil con la academia. Ademas, facilitara la administración del negocio y mejorara la experiencia de los usuarios.

# Épicas e Historias de Usuario

Las épicas representan las funciones principales que tendrá el sitio web **Stevan Dance Studio**. A partir de ellas se crean las historias de usuario, que describen lo que cada tipo de usuario necesita hacer dentro de la página.

## Tipos de usuarios

- **Visitante:** Persona que entra al sitio para conocer la academia.
- **Estudiante:** Cliente registrado que puede inscribirse a clases y consultar su información.
- **Administrador:** Propietario de la academia (yo), encargado de administrar cursos, estudiantes y eventos.

## Épicas

1. Conocer la academia.
2. Gestionar la cuenta del estudiante.
3. Inscribirse a cursos de baile.
4. Consultar horarios y eventos.
5. Administrar la academia.
